# 星座运势与木鱼

2026-10-05，beta.23实现。`launcher.c/APPS` 在原17个App后追加 `app_zodiac`、`app_merit`；已有顺序、实体返回/计时映射和字体像素保持不变。

## 星座运势

`app_zodiac.c` → `zodiac_fetch_begin(sign,token)` → 独立FreeRTOS HTTP任务 → `zodiac_data_parse` → `zodiac_fetch_poll` → LVGL展示。

- 点星座名称或“切换”进入12项列表；系统返回先收起列表，再退出App。左右按钮切换综合/爱情/事业/财富/健康。正文用32px原生字库完整换行，中央矩形区域原生滚动，不截断长文。综合页还列出幸运颜色、数字、贵人星座和宜/忌。
- 数据为[小小API星座接口](https://xxapi.cn/doc/horoscope)中文原文；英文系统界面标注 `Chinese original`。GET参数只包含公开星座key、today和设备日期，无账号、密钥、位置或私有数据。沿用答案之书已有提供方，不增加收费依赖。
- 2026-10-05实查12种key均返回200、正确星座和10月5日；日期参数不改变接口schema。文档样例的幸运数字/颜色出现互换，实际响应类型正常；实现按实际字段展示，不自行调换。
- 使用已有ESP-IDF 6.0.1 HTTPS证书包，禁重定向，6秒I/O超时、8秒读取期限，8KiB响应上限。服务解析校验200业务码、所选星座、严格UTF-8、字段容量及0至5整数评分；未知评分显示 `-- / 5`。设备日期有效时只接受当天日期，防旧响应冒充今日。进入/选星座/刷新联网；可见页跨日自动更新。没有离线随机运势。
- 取消只推进generation，旧任务自行关闭连接/释放内存。快速切换遇到BUSY时在UI期限内等待旧任务退出，再发所选星座请求，不并行堆任务。离线、HTTP失败、超时、无内容和缺字各显示明确状态；刷新可重试。隐藏页停止poll，退出取消请求并清空UI指针。
- 字体复用 `font_answer_32` 和3755字CJK fallback。12份真实响应检出“橘羯逅邂馨”缺字，加入 `artwork/zodiac/extra-glyphs.txt`，由 `gen_answer_font.swift` 生成；原309字的bitmap逐字未改变。真实接口去重字集保存在 `tests/lifestyle/horoscope_glyphs.txt`，覆盖当天全部12种响应的5类文本及幸运字段。未来遇到字库外内容明确提示，不显示方块。共享24px字体增加32字，原1460字bitmap未改变。

## 木鱼

`app_merit.c/knock`由木鱼触摸或右上PWR短按触发：计数加1 → `+1`上浮/淡出与木鱼/敲击棒运动 → `audio_out_knock`异步播放。

- 每次有效敲击独立计数；动画重新起步，音频输出忙时不排队。上限999,999,999，避免溢出。静止页不持续重绘，遮挡/锁屏停止动画时钟与按键积压。
- `merit_store.c`使用独立NVS namespace `merit`、u32 key `count`。不移动分区、不改其他设置格式。2秒无敲击后合并保存；连续敲击最长20秒保存一次，失败重试至少间隔2秒；隐藏/退出再保存。突然掉电可能丢失尚未保存的末段计数。
- 没有旧记录时从0开始；读取错误或超范围记录显示 `--`，点击重试读取，不覆写未知旧值。写入失败显示保存失败并保留RAM计数，退出/重进仍尝试保存；并非伪装为已持久化。
- 复用ES8311/I2S输出worker和麦克风互斥 `audio_bus`，新增95ms双频指数衰减木声，保留闹钟与设置试听分支。音量服从系统设置，系统静音优先；App内声音开关只控制本App。退出释放音频占用，下一App可使用麦克风。未引入音频资源文件或解码器。
