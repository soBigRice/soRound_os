# v1.7-beta.35 · 启动器字库与居中音乐控件

## 本版变化

- 修复新App在真实启动器名称中显示方块：直接选中、切换动画中点及返回统一选择完整字库；旧App字体保持原样。
- 音乐三键移到屏幕中线：播放/暂停位于正中央，112×112触点、40px图标；上一首/下一首分列两侧。静态透明底，按下有轻微反馈。
- 曲名与歌词分置控件上下，封面继续作可旋转背景；复用原文字缓冲和协议。无回传时不假造播放状态、封面或歌词。
- 鼠标、翻页、音乐仍沿用标准BLE HID；本版不要求Mac桥接即可发送播放/暂停、上一首、下一首。原音量/静音继续通过长按“音乐”打开。
- 修复手动Mac媒体桥接的两个问题：相同封面遇进度更新时被误清除；macOS已连接外设仅用HID服务查询时漏检。增加脱敏服务计数及写入失败上下文。

## 仍未完成的功能

- **封面/文字的真实BLE传输尚未通过。** 已实测读到系统曲目和真实封面，并发现自定义媒体服务、完成加密STATUS读取；后续ATT写失败，封面和文字层均没有完整提交ACK。本版不能承诺背景或歌词已能在设备显示。
- 歌词目前仅支持显式绑定曲名的本地LRC，不会自动取得任意播放器歌词。桥接保持手动启动、不自启、不联网；错误诊断不输出歌曲、封面或设备标识。
- 声音胶囊“存储未配置”需要独立录音分区初始化，**本次应用OTA不解决该存储迁移**。未配置时保留保护，不自动格式化。

## 升级与验证边界

- 继续使用双8MiB应用槽。旧3MiB/4MiB槽需另行USB迁移，普通OTA不能扩大分区。
- 已有双8MiB应用槽可通过内测OTA安装本应用镜像；已有设置和资源分区不会因普通OTA自动迁移。
- 用户本轮选择暂不写设备：发布不执行USB烧录、分区迁移或录音卷初始化。启用录音前仍须完整备份并审查迁移方案。
- CI以发布依赖执行固件构建、48项主机回归（含真实启动器名称字形）、2项生态箱/专注、媒体ASan/UBSan及14项OTA镜像检查。自动检查不等于真机触摸、视觉、实际媒体控制或录音验收。

正式通道保持v1.7；本次仅更新beta通道。
