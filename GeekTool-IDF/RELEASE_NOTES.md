# v1.7-beta.36 · 九款 STUDIO 创意表盘

在原21款之后追加雷达、磁带、光圈、迷宫秒、翻页、像素夜营、地平线、潮汐与年轮，共30款。原有表盘和NVS选择记录保留。

- 设置 → 表盘增加STUDIO组，继续支持左右循环、居中缩略图、即选即存和返回。BOOT锁/解锁、常显与熄屏策略保持。
- 按确认稿还原字体字号、基线、字距、色彩、透明度和曲线路径，提供真正466×466的LVGL正常/AOD原生对照；图片见[原生审图](https://github.com/soBigRice/soRound_os/tree/v1.7-beta.36/GeekTool-IDF/artwork/watchfaces/studio-native)。RGB565及字体栅格化与浏览器有固有差异，未宣称逐像素全等或真机验收。
- 雷达扫线、磁带卷盘、光圈秒标、迷宫秒球、像素场景、潮汐浮标与年轮秒针随时钟更新。翻页及地平线按分钟变化；日夜、波纹和场景不冒充真实日出、潮位或养成数据。
- 新款复用原生LVGL与现有1Hz计时器，不增加全屏常驻画布、矢量引擎、联网数据源或持久化格式。AOD停秒动画，隐藏/熄屏停计时器。
- 修复启动检查把新增同余ID误判为图片表盘的边界，保留旧4/9/14的图片解码等待。新增正屏/预览字形检查，防止冒号或小字被fallback掩盖。

## 升级与验证边界

- 本包继续要求双8MiB应用槽；普通应用OTA不扩大分区，也不格式化或迁移资源与录音卷。
- 用户明确本轮不烧录：没有USB访问、设备写入、分区迁移或录音初始化。
- 发布CI执行ESP32-S3构建、50项主机回归、2项生态箱/专注、媒体ASan/UBSan及14项OTA镜像检查。自动验证与原生图不能代替设备触摸、亮度、功耗和升级重启验收。
- 前版限制继续保留：电脑三键仍为标准BLE HID；封面/文字回传仍有ATT实测失败，歌词目前仅显式绑定本地LRC；声音胶囊需要独立录音卷初始化。

正式通道保持v1.7，本次只更新beta通道。
