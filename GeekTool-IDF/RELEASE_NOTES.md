# v1.7-beta.37 · 表盘绘制栈与木鱼虚影修复

- 九款 STUDIO 保留原设计及原有21款表盘。将多边形与圆环扫描数组移出深层绘制栈，全部 STUDIO 共用一个2,084B工作区；ESP32-S3对应函数栈帧由2,368B/1,232B降至288B。没有降低分辨率、采样或动画频率。实机设置预览在原7,168B任务栈仅余424B，因此另以2KiB内部RAM将LVGL任务栈显式设为9,216B，保留看门狗。两种实际像素格式下，修复前后各89帧逐字节一致。
- 木鱼主体固定在原位置、原尺寸并保持不透明；敲击时另绘放大至约110%、360ms内淡出的虚影。保留木槌回弹、完整功德提示、声音、计数与存储策略。真实JPEG逐20ms渲染回归覆盖单敲、连敲与遮挡恢复。
- 星座保留同次请求的设备日期、返回日期、HTTP/TLS、传输阶段及失败分类，区分内存、连接、超时、响应完整性与日期不符；取消后的旧请求不能读取新诊断。提供方、日期校验、超时和重试规则保持。

## 验证与升级

- 本地使用发布依赖 LVGL9.6.0~1 / ESP-IDF6.0.1，53项主机回归、2项生态箱/专注、媒体ASan/UBSan及14项OTA镜像检查通过；发布CI重新执行同一门禁。
- ESP32-S3实机完整约283秒轮测：九款正常/AOD、39次设置预览、跨分钟、息屏唤醒、RADAR连续70秒及木鱼视觉反馈完成，未见panic/渲染停滞，实际LVGL栈最低余量2,952B。白羊座五次真实页面请求均HTTP200、日期正确；历史失败未复现，不能据此宣称其原因已查明。
- 本包要求双8MiB应用槽。普通应用升级不扩大分区、不迁移或格式化资源与录音卷。当前USB安装按用户授权只写另一应用槽及启动选择，保留原beta.35回退应用、设置和表盘文件。
- 设备触摸、主观观感、扬声器音色、功耗及失败自动回滚仍需分别验收；本轮USB安装不代表设备网络OTA链路通过。
- 前版限制保留：电脑三键为标准BLE HID；封面/文字回传仍有ATT实测失败，歌词仅显式绑定本地LRC；声音胶囊需要独立录音卷初始化。

正式通道保持v1.7，本次只更新beta通道。

# v1.7-beta.36 · 九款 STUDIO 创意表盘

在原21款之后追加雷达、磁带、光圈、迷宫秒、翻页、像素夜营、地平线、潮汐与年轮，共30款。原有表盘和NVS选择记录保留。

- 设置 → 表盘增加STUDIO组，继续支持左右循环、居中缩略图、即选即存和返回。BOOT锁/解锁、常显与熄屏策略保持。
- 按确认稿还原字体字号、基线、字距、色彩、透明度和曲线路径，提供真正466×466的LVGL正常/AOD原生对照；图片见[原生审图](https://github.com/soBigRice/soRound_os/tree/v1.7-beta.36/GeekTool-IDF/artwork/watchfaces/studio-native)。RGB565及字体栅格化与浏览器有固有差异，未宣称逐像素全等或真机验收。
- 雷达扫线、磁带卷盘、光圈秒标、迷宫秒球、像素场景、潮汐浮标与年轮秒针随时钟更新。翻页及地平线按分钟变化；日夜、波纹和场景不冒充真实日出、潮位或养成数据。
- 新款复用原生LVGL与现有1Hz计时器，不增加全屏常驻画布、矢量引擎、联网数据源或持久化格式。AOD停秒动画，隐藏/熄屏停计时器。
- 修复启动检查把新增同余ID误判为图片表盘的边界，保留旧4/9/14的图片解码等待。新增正屏/预览字形检查，防止冒号或小字被fallback掩盖。
