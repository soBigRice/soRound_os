# 音频与水平仪：谱线与靶心

核对日期：2026-10-04。用户已选定 466×466 小稿 v3，并授权按稿移植；原生实现已完成主机渲染与构建验证，真机拾音、姿态及主观效果待验收。

## 入口与边界

`launcher.c:enter_app → app_audio / app_level.enter → tick`。共享返回键仍走 `app_back`，电量环仍读 `power_read`，充电/低电量与遮挡行为不变。`header_app_style` 只给这两个工具使用 `tools_header` 的标题、返回键与灰色轨道；离开后恢复原有样式。

`tools_ui.c/h` 集中维护这两页的黑、白、灰、红与平滑字体、基线排版、绘制图元及故障页。`tools_label_center` 会先清除已有对齐锚点，避免启动器原来的 `TOP_MID` 被当作坐标偏移。字体由 `tools/gen_tools_fonts.swift` 通过本机 CoreText 导出 `font_tools.c`，仅包含当前文案与数字，4bpp 位图合计 21,254 字节；其他页面字库不变。

## 音频

`audio_task → audio_mic_read(480) → 18 个 Goertzel 频点 → capture_publish → audio_tick → spectrum_draw`。

- 16 kHz、80 Hz–6 kHz 对数频点、增益 11、快上慢下的能量滤波保持原值。采集任务独占音频总线，遮挡时暂停读帧，退出自行释放；失败启动仍按激活代次抑制重试。
- 每次发布核对 `s_run/s_generation`，旧激活的迟到读帧不能覆盖新页状态。UI 只读取临界区快照；worker 不调用 LVGL。
- 18 列 ×16 行，间距 17/10px，底部 y=303，点直径 6px（小稿 6.2px 在整数 RGB565 栅格上的对应尺寸）。一个固定绘制对象，不建立 288 个对象；只有变化的列/行区域失效化。
- 点亮数量 `max(1,round(energy×16))`。列顶为主题红，内部按 `.72×行高+.28×频段能量` 从冷白、浅青、暖杏到柔玫红连续插值，再以 `.85` 强度混色。全部列处于一个点的区间时显示白色「聆听中」。颜色不随独立计时器变化。
- 状态点/文字 y=111，频率基线 y=326，频率标签 y=353，说明 y=395，频段数 y=423。
- `CAPTURE_STARTING` 显示正在启动，首个有效帧进入 `READY`。真实启动失败、任务创建失败或三次连续无效读帧才显示故障；后续有效帧可恢复。静音不会判作麦克风故障。没有播放按钮、曲名或未经校准的 dB。

## 水平仪

`level_tick → imu_read_tilt_z → 同帧总角度/X/Y → 投影限位/时间消抖 → 气泡与读数`。

| 元素 | 原生坐标/尺寸 |
| --- | --- |
| 靶盘 | 中心 `(233,210)`，半径 100，72 点，内圈 64/32 |
| 外伸刻度 | 圈外 5–13px，整数线宽 2；完整绘制包围 y=96–324 |
| 气泡 | 半径 14，最大圆心偏移 81；白色/明显倾斜红色，中央黑点 |
| 状态 | 中心 `(233,341)` |
| 总角度 | 60px 平滑数字，基线 y=401 |
| 度数单位 | 24px，独立上标，基线 y=379；与数字间隔 7px，按两者实际宽度整组居中 |
| X/Y | y=427，中心 x=199/300，X/Y 标签 x=164/264，分隔线 x=233 |

投影增益改为 `500×81/168`，与原来 500px/168px 的约 20° 饱和点一致。`SMOOTH=.35` 与按实际 dt 计算的滤波、总角度 `asin(clamp(hypot(tx,ty)))` 四舍五入、两轴 `atan2(axis,max(abs(az),.05))` 整数截断全部保持。没有增加惯性或改变校准。

首次显示前必须获得有效样本；三次连续无效或非有限读数隐藏旧气泡与整个读数区，显示传感器故障，恢复后重新显示实时数据。传感器恢复仍由既有 `imu.c` 负责，不重置共享总线。正常页用总角度是否为零显示「已水平/偏离水平」。

## 穿透问题与防线

此前用户两次指出文字被穿透：第一次只修正点阵数字与单位；第二次发现靶盘底部外伸刻度仍穿过状态文字。旧稿中心 y=221、半径 112，计入外伸 13px 和圆头线宽后到 y=346.75，跨入 y=341 的状态行。不能只检查圆周或整个页面是否在圆屏内。

当前把完整靶盘包围盒和文字区分开，不用黑底遮盖图形。`tests/host/settings_level_tests.c` 检查外伸刻度包围、数字/单位实际字形上边界、整组居中、四向气泡极限及传感器异常恢复；覆盖中文/英文 0°、9°、85°、90°。后续任何刻度或字号改动必须检查完整图元及字形边界。21px 字体去掉布局框中的空白栅格补边，保持相同的居中基线与位图，避免 X/Y 标签的空白盒越过圆屏边缘。
