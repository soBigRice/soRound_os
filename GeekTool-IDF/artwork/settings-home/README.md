## 实现与边界（beta.29）

`app_settings.c:settings_enter → rebuild → SETTINGS_HOME → home_row`。
四分类顺序保持：显示与表盘、声音、语言、关于本机。首页使用透明行、细分隔线、24px标题/18px真实状态和原生36px线条图标；关于入口复用 `identity_logo_create`。
首页列表采用LVGL纵向Flex，88px行高、16px行间距、上下14px留白，居中278px触摸行；466×298滚动视口从y=110开始，首屏显示三项，向上滑动查看关于本机。
标题、44px返回按钮与电量不参与滚动。`home_scroll_draw`在首页根面板绘制右侧弧形位置提示，`home_scrolled`仅使该提示区域失效。
亮度/音量与常显/静音状态继续读取真实设置；移除重复的状态前缀。按下时整行反馈，装饰图标、标志和分隔线不接收点击。

`open_page → queue_rebuild → rebuild`：销毁旧面板前保存 `s_home_y`，重建首页并完成布局后恢复位置；`settings_enter`和`settings_exit`清零，重新进入从顶部开始。
`settings_back`仍由表盘返回显示，其他子页返回首页；首页再返回由启动器退出。退出取消待执行重建，清空列表指针；页面销毁由LVGL释放输入目标和惯性动画。
beta.29只改首页，没有修改共享 `control_ui`、Wi-Fi、子页布局、设置保存、表盘、音频或开机流程，没有新增字体、位图、线程或依赖。
用户后续明确要求全部设置项单独进入，并选择首页直接列出七项；当前工作区实现见[独立设置项与居中表盘](../settings-detail/README.md)。本目录保留beta.29四分类基线图和验证记录，不代表当前七项首页。

原生滚动设置仅允许纵向、有惯性、无回弹、无向父级滚动传递，保留手势冒泡与既有右滑返回。行继续使用 `LV_EVENT_CLICKED`，其原生语义只在未滚动的松手时触发。
核查依据：本项目LVGL9.5源码 `src/indev/lv_indev.c`、`src/core/lv_obj_tree.c`；官方[滚动说明](https://lvgl.io/docs/open/9.5/common-widget-features/scrolling)和[事件说明](https://lvgl.io/docs/open/9.5/API/misc/lv_event_h)。

## 验证纠正记录（已解决）

首次编译因测试调用私有`lv_area_intersect`失败，改为测试内部矩形交集。初始测试页有父对象且默认可滚动，手势边界与`launcher.c:enter_app`不同；对齐屏幕边界后，右滑仍失败，说明边界不是完整根因。
本轮曾按用户修复上限暂停；用户明确“那你继续处理”后继续定位。LLDB捕获同一触摸点被`touch_at → lv_indev_read`和`lv_timer_handler → lv_indev_read_timer_cb`重复读入：第二次位移为零，`indev_gesture`按最低速度规则清零累计，所以120px手势未越过64px阈值。
原因在测试输入驱动；LVGL事件模式按下后会恢复读入计时器。现改用单一原生定时输入路径，并按设备启动器创建屏幕；保持手势阈值与回归断言，未改设备返回逻辑。再次执行双语全流程及上下滚动补查均通过，暂停状态已结束。

## 纠正与防复发

小屏不等于必须将全部入口塞进一屏。此前压缩四项密度遗漏了用户对留白与可滚动的要求，现明确首页以原生滚动换取行距和完整触摸区域。
后续首页调整先按466×466实际渲染检查顶部、底部和滚动中内容，再验证点击与返回；不能只看静态首屏。
主机手势测试应与 `launcher.c:enter_app` 的屏幕边界和滚动标志一致，并只保留一个输入采样路径，避免默认对象行为或重复静止采样冒充真实设备问题。
构建失败必须立即停止测试命令，禁止执行旧二进制并把旧结果计为本轮通过。临时构建、PPM、调试器和日志在结束时清理，只保留有用PNG与交接证据。

本轮临时主机构建、基线二进制、PPM、测试/本次IDF日志已清理；无测试或调试器进程残留，保留可审阅PNG与有效候选固件。
