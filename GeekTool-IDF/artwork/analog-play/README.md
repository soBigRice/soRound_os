## 当前实现与本次目标

旧`main/watchface.c`和`watchface_ui.c`十五款组合表盘之外，本轮已追加：

- **HAND / MARK「刻度」**：完整分钟刻度、12/3/6/9数字、宽时针与细分针、红色秒针；日期/电量在中心下方。
- **HAND / ARC「弧时」**：十二段小时标记、镂空时针与细分针，外弧显示分钟、红点显示秒；省去四个大数字。
- **HAND / NUMERAL「字时」**：十二个数字、柳叶时分针、独立小秒盘，优先直接读时。
- **HAND / ORBIT「轨迹」**：红色圆形时针沿内轨道走动，白色细分针指向外圈。
- **HAND / FRAME「方构」**：方形刻度轨道、四段粗标记、平头指针与方形轴心。
- **HAND / DOTS「点刻」**：点阵小时刻度、圆头指针与点阵日期，延续设备的点阵语言。

实现使用附加索引15–20，保留旧0–14与自定义图片语义。固件选择器已新增独立HAND组，
不套用旧“每组固定五款”的`%5`/`/5`规则；渲染、名称、缓存刷新、设置保存同步更新。
活动态按秒走时；常显隐藏秒针/秒点和附加信息，仅保留刻度/时分针，按分钟刷新。
本轮保留BOOT解锁、锁屏、亮度和电源策略。

旧`main/app_maze.c:maze_gen`每次进入/过关生成6×6随机迷宫，缺少关卡索引、选关和完成进度。

不引入倒计时、生命数、陷阱、付费解锁或新的传感器权限。

主路线由 `levels.js:authored` 显式设计；剩余格子以固定顺序接为支路，保持全部连通、无捷径。

旧`main/app_fluid.c`用240个独立白/红圆粒渲染。首版银色液面被用户反馈难看；
本轮用户明确选择**彩色染料：颜色柔和交融、能拖动搅开**。原银色稿只保留在
`rejected-silver.png`，已不作为当前实现方向。
用户随后确认保留原粒子，染料作为第二模式；固件已通过“粒子/染料”按钮切换，未替换原物理后端。

当前浏览器原型为「染流」：青蓝/陶橙、松绿/米金、烟紫/珊瑚三套柔和配色；
拖动注入染料与局部速度，染料随速度场被拉开、卷曲和混合，每次新的拖动切换注入颜色。
暂停停止输运，仍可注入/重置；切换配色恢复初始色带。颜色显示按密度归一，避免反复注入后全部变白。
`ink-fluid.js:createInkStudy` 使用116×116速度/压力网格、466×466染料纹理与最终输出，
执行速度平流、涡量、压力投影和染料平流。`ink-fluid.js`只用于浏览器原型，对应固件CPU实现为`main/fluid_ink.c`。

选择浏览器已有WebGL2是为了可审阅真实拖动、卷曲与混色，不新增包管理器、CDN或依赖。
仅将旧粒子换色、静态渐变水滴或旋转图片不能表达这次选定的交互，故没有继续采用。
API与浮点帧缓冲能力对照 [Khronos WebGL2规范草案](https://registry.khronos.org/webgl/specs/2.0.0/)，
2026-10-08核查；原型运行时检查WebGL2、扩展、着色器与帧缓冲，不支持时明确显示限制。

固件采用独立CPU密度场，接入现有IMU、真实LVGL触摸、暂停/静止休眠及退出清理；
内部64×64网格插值输出466×466，与浏览器GPU的116×116/466×466纹理分开。
没有移植WebGL；原粒子数、物理与频率保持。原生拖动/生命周期已自动验证，
浏览器GPU与主机LVGL都不能证明ESP32帧耗时、真实触摸手感或IMU响应，仍需设备验证。

可复用纠正：需要“染料交融”时，先核对颜色是否随真实流场输运，再审阅材质；
上一版连续液面近似只能表达倾斜回摆，固定水滴与金属反光不符合本次偏好。
此次避免用静态装饰替代混色交互，并分别保留浏览器验证、待用户审阅和待设备验证状态。

## 原型调用链

```text
index.html → levels.js（固定地图）+ ink-fluid.js（浏览器染料）+ preview.js（输入/绘制）
  表盘：常显/走时按钮 → clocks → drawClock（六款）
  迷宫：选关/重玩 → resetMaze → 倾斜替代输入 → simulateMaze
      → 圆球/墙体碰撞 → 红色目标 → win → 用户选择下一关
  染料：拖动 → stirInk → inject（颜色/速度）→ step → render
      配色/重新注入 → setPalette/reset → 清空纹理并建立初始色带
  流体进入可视区 → 创建渲染器；移出可视区 → 停止GPU绘制
  页面隐藏 → suspend；关闭/离开 → 取消动画、清空输入、释放GPU资源
```

鼠标按住迷宫圆屏拖动代替IMU，聚焦后可用方向键。染料圆屏拖动用于搅动和注入，
左右方向键施加反向旋转流场，下键重新注入。“常显预览”与“走时预览”各自只影响对应表盘；
常显态隐藏秒显示，走时仍按常显规则保持静态。系统减少动态效果时默认停止染料流动，用户可主动播放。
原型流体返回按钮用于恢复预览，设备应用返回继续沿用现有共享行为。
没有网络接口、遥测、后台轮询或持久化写入。上下文丢失会显示错误，离开页面会删除纹理、
帧缓冲、程序、着色器和顶点缓冲；返回缓存页面时重新建立渲染器。
