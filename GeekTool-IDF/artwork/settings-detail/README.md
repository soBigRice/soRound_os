## 纠正与当前布局

用户先反馈二级页拥挤、截断，首轮尝试将混合控制页滚动排列；随后继续指出表盘不居中、设置项应点入独立调整。
只增加滚动仍让一页混合多个任务，表盘预览也随滚动偏离圆屏中心。当前采用用户明确选择的结构：
首页七个选项，仅呈现名称/当前状态，点击才进入调整。之前未验收的混合子页改稿由本稿替代。

左右按钮(52,205)/(364,205)、50×56；计数y=354、三组72×44按钮y=385，保持圆屏范围和至少44px触摸高度。
上下拖动不会移动预览或改变选择，选择/切组重建后仍居中，不缩小十五款原生预览。

## 入口与状态链

`app_settings.c:settings_enter → rebuild → SETTINGS_HOME → home_row → open_page → queue_rebuild → rebuild`。
七个内页直接从首页进入；打开页面本身不写设置。首页读取真实亮度、表盘名、常显、音量、静音和语言状态。
`settings_back`从任一内页返回首页，首页再返回退出App；原生右滑与启动器返回按钮均恢复首页滚动位置。
`rebuild`销毁旧面板前用`s_built_page`保存旧滚动页位置；重建目标页并完成布局后恢复。
重新进入App清零位置，退出取消异步重建，清空输入/预览指针。LVGL销毁输入目标和惯性动画。

`slider_changed`按亮度/音量页分别调用真实设置API，`LV_EVENT_RELEASED → save`才落盘。
`toggle`按常显/静音页分别设置空闲模式或全局铃声静音，单次保存后重建当前页，不返回首页。
`pick_face/pick_theme`仍立即选择/保存，组名保留五种用途；`pick_lang`立即保存/重建本页。
只有音量页初始化音频用于试听，离开该页或退出就释放；静音页不初始化音频。
NVS格式、亮度下限、铃声/提示音语义、十五款渲染与索引、Wi-Fi、共享`control_ui`、锁屏和开机动画未修改。

## 后续设计约束

在设置中，一项参数对应一个独立调整任务；首页承担导航和状态，不混放滑块/开关。
滚动用于承载长选项列表或硬件信息，表盘选择使用固定居中画面。按466×466真实圆屏审阅顶部/底部、完整控制区和动态选择，
不把“内容可滚到”当作“每项任务清楚且完整可操作”。此约束只适用于当前设置App，不推广改动其他已确认页面。
