## 开机动画

| 时间 | 视觉变化 |
| --- | --- |
| 0.136–0.408s | 红点从圆环右下方淡入 |
| 0.204–1.700s | 红点绕圆环中心走90°短弧，归位到右上角 |
| 0.272–1.530s | 白环从右下起点绘制一周，结束保持完整轮廓 |
| 1.820–2.300s | 系统名淡入，上移7px |
| 2.500–2.800s | 系统检查文字淡入 |
| 2.800–4.000s及之后 | 保持；自检通过且最短时长完成后放行，未完成/失败继续显示状态 |

环与红点只在中心小区域变化，无全屏移动、模糊、假进度或网络依赖。浏览器 SVG/SMIL 是效果参考；
设备使用 `identity_ui.c` 的LVGL圆弧/圆点和单次动画，不引入SVG解析器、不播放视频；可选HTTPS检查使用独立worker。
几何与颜色从同一SVG生成`identity_geometry.h`，原生缓动使用项目已有`lv_cubic_bezier(.22,.61,.36,1)`。

启动链：`main.c:app_main → identity_boot_create → launcher_start → 图片/Wi-Fi初始化 → startup_selftest → startup_apply_ota_result → startup_network_check → identity_boot_release`。
覆盖层先创建，原启动器与锁屏表盘建立后再将覆盖层置顶；保留原页面并遮住电量、表盘及触摸。
释放LVGL锁后并行预热图片/启动Wi-Fi；核心检查与至少4秒完成后才确认OTA，联网失败不回滚。
`boot_advance`推进圆环、红点、系统名和状态；中心标志1.7秒后停止失效化，4秒后未就绪则保留静态状态。
`boot_completed`与`identity_boot_release`共同控制删除覆盖层，恢复原锁屏表盘；启动时阻止短按越过覆盖层，保留长按关机。
提前删除覆盖层时，LVGL同时删除绑定在该对象上的动画，不清理其它对象的动画。
覆盖层分配失败不露出半初始化首页；早期panic及待确认OTA由原bootloader回滚处理。
完整放行条件、错误处理与SDK边界见 [启动逻辑](../../STARTUP.md)，当前状态图见 [原生审阅](./native/startup-20261007/README.md)。
生命周期依据：[LVGL 9.5 Animation API](https://lvgl.io/docs/open/9.5/API/misc/lv_anim_h)，关键接口已核对当前本地依赖并通过真实LVGL回归。

原生入口：`main/identity_ui.c/h`、`main/identity_geometry.h`；字形源`tools/gen_identity_fonts.swift → main/font_identity.c`。
后者保留原16/26/34px字形数组和描述符；独立增加18px中英文状态子集（80字形、6630B的4bpp bitmap），不改全局主题或其它App字体。
