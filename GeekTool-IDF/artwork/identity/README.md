## 开机动画

| 时间 | 视觉变化 |
| --- | --- |
| 0.08–0.24s | 红点从圆环右下方淡入 |
| 0.12–1.00s | 红点绕圆环中心走90°短弧，归位到右上角 |
| 0.16–0.90s | 白环从右下起点绘制一周，结束保持完整轮廓 |
| 1.02–1.30s | 系统名淡入，上移7px |
| 1.30–1.80s | 保持，结束定格 |

环与红点只在中心小区域变化，无全屏移动、模糊、假进度或网络依赖。浏览器 SVG/SMIL 是效果参考；
设备使用 `identity_ui.c` 的LVGL圆弧/圆点和单次动画，不引入SVG解析器、不播放视频、不新增任务。
几何与颜色从同一SVG生成`identity_geometry.h`，原生缓动使用项目已有`lv_cubic_bezier(.22,.61,.36,1)`。

启动链：`main.c:app_main → display_init → settings_init → i18n_init → touch_init → launcher_start → identity_boot_create(lv_layer_top())`。
`launcher_start`仍创建原启动器与锁屏表盘并默认锁屏；启动覆盖层最后创建，遮住电量、表盘及触摸，原页面保持存活。
随即释放LVGL锁，按原顺序预热图片、启动Wi-Fi、确认OTA新镜像。动画与这些服务并行，未加入等待/延时，也不因动效完成提前确认OTA。
`boot_advance`推进圆环、红点和系统名；中心标志1秒后停止失效化，文字1.3秒后不再变化。
1.8秒完成后`lv_obj_delete_anim_completed_cb`删除覆盖层与子对象，露出原有锁屏；没有改变常显、语言、按键或已保存表盘。
提前删除覆盖层时，LVGL同时删除绑定在该对象上的动画，不清理其它对象的动画。
分配失败会记录日志并显示已就绪的原有界面，不阻塞启动。
生命周期依据：[LVGL 9.5 Animation API](https://lvgl.io/docs/open/9.5/API/misc/lv_anim_h)，关键接口已核对当前本地依赖并通过真实LVGL回归。

原生入口：`main/identity_ui.c/h`、`main/identity_geometry.h`；字形源`tools/gen_identity_fonts.swift → main/font_identity.c`。
后者仅导出系统名和屏幕说明的28个字号/字形组合，共3223B的4bpp bitmap，不改全局主题或其它App字体。
