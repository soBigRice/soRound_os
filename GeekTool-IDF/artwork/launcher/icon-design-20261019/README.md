# 启动器图标重设计 · 2026-10-19

状态：用户已选定A黑白实心；原20项与追加3项共23项已接入，69种原生状态与发布CI通过，随v1.7-beta.34发布；设备效果待验收，未烧录。实现及准确发布证据见[图标说明](../../../LAUNCHER_ICONS.md)。

本次处理 `main/launcher.c / APPS[]` 注册的20个启动器应用图标。用户反馈原有图标过于线条化，部分出现错位。源码核对确认，除木鱼等少数图标外，当前实现主要通过7px线段、圆弧和边框拼接；圆屏中央控件统一居中，但各符号的可见边界、留白和视觉重量并不相同。用户指出的具体错位尚未通过设备画面复现，不能将其直接归因为控件坐标或底层渲染错误。

## 共同约束

- 设计画布148×148，圆屏466×466；196×196按钮居中上移16px，应用名称位于原位置。真实固件继续单应用居中显示，图标合辑仅用于审阅。
- 应用身份、名称、注册顺序、点击范围、导航方向、220ms切换和电量环是本次不变项。三稿只比较图标；不借重设计改系统布局。
- 白色大块面、足够宽的负形和可辨识轮廓优先，不再用零碎细线拼接。图标按实际内容边界统一到相近尺寸，结合面积重心作有界视觉校准；不按SVG容器边界盲目缩放。
- 木鱼沿用已确认的白色实心轮廓及斜向开口，不添加木槌、鱼眼和卷纹。水平仪、迷宫、双生、方块使用与实际应用含义一致的局部造型。
- A为黑白实心，强调形体与少量红色；B为柔和彩色，以圆角色块承托实心符号；C为像素块面，用连续像素群保留轮廓，不使用稀疏点阵描边。
- 三稿均是浏览器设计预览，74%电量为固定夹具，不代表设备电量。设备AMOLED、切换中间帧与触摸要在选定方向并接入后另行验证。

## 来源与生成

通用符号使用 [Phosphor Icons](https://github.com/phosphor-icons/core) 的fill/bold源SVG，核查版本 `@phosphor-icons/core 2.1.1`，MIT许可，核查日期2026-10-19。仅保留本次使用的SVG及其许可证，不安装运行时图标库。原生几何拼接不再作为新稿的曲线来源；官方源SVG能复用统一形体、避免逐个重拟合带来的接缝和比例差异。Fluent Color也作了覆盖检查，但缺少本项目多种工具的对应符号，未混入该图标体系。

`build-preview.cjs` 读取本目录 `sources/` 中的确定性向量素材，以sharp测量透明内容边界并生成预览；不改动 `main/`、依赖锁、构建配置和既有木鱼候选。运行时使用已有Node+sharp，不新增项目依赖。

生成的 `a-solid.html`、`b-color.html`、`c-pixel.html` 可独立打开，包含完整20图标、可切换的圆屏预览及校准检查模式。`index.html` 是三套的统一比较入口；所有图标内嵌，无CDN或外部网络依赖。

`current-native.png` 是替换前的原生对照；`native/` 是A稿接入后的真实LVGL渲染。三方向浏览器页面继续作为设计留档，不能替代设备验收。

已按 `direction-approved.md` 记录的用户选择完成A稿接入。选定A稿的精确SVG/PNG固定在 `selected/`；生产转换只读取这里的20项和摘要，不从历史三方向页面重新推导。转换、调用链、缓存边界及回归入口以 [LAUNCHER_ICONS.md](../../../LAUNCHER_ICONS.md) 为单一实现说明。
