## 生成与验证

- `tools/gen_merit_icon.js` 使用Node + sharp渲染源SVG，并调用项目自带LVGL9.5官方 `scripts/LVGLImage.py`（Python + pypng/lz4）生成 `main/merit_icon.inc`。运行方式：在GeekTool-IDF目录执行 `node tools/gen_merit_icon.js [python路径]`，所用Node需能解析sharp。没有更换工程依赖或设备解码器。
- 资源为148×148 A8，RLE无损压缩后含头1758B；绘制期间现有解码器使用21904B像素缓冲。工程图像缓存为0，绘制关闭解码器时释放临时资源。
- 采用现有解码器，是因为当前工程未启用SVG/向量引擎；使用现有几何图元重拟合会改变已确认曲线。核查来源：[LVGL9.5图像与离线转换器](https://lvgl.io/docs/open/9.5/main-modules/images/adding_images)，核对日期2026-10-13；本地9.5源码已核对A8/RLE解码、着色及RGB565混合。
- `native-merit-zh.png`、`native-merit-en.png`、`native-merit-fade.png` 为实际LVGL9.5原生466×466渲染。排除既有按钮边框后，全部图标像素与源SVG的alpha经LVGL RGB565混合后的结果一致；50%淡出主体最大通道121。`startup_complete_flow`通过。
- 初次像素比较直接使用浏览器风格RGBA合成，误计了画布角落既有按钮边框，并忽略RGB565的alpha混合量化。应先区分图标资源、已有界面覆盖物和目标渲染格式，不通过调形状掩盖比较方法问题。
- 固件构建：ESP-IDF6.0.1 / ESP32-S3 / LVGL9.5.0，版本 `v1.7-beta.33-1-g3c0149a-dirty`，4160304B，4MiB槽剩34000B。构建及镜像校验通过；烧录证据保存在被Git忽略的 `build/flash-records/merit-icon-20261013/`。
