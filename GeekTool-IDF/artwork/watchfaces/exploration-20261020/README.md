## 固件实现边界

固件追加索引21–29，保留旧索引0–20、NVS格式、233px居中预览、即选即存、BOOT锁/解锁和当前隐藏/熄屏行为。不需要录音分区迁移，也不读取新传感器。现有计时器为1秒；本设计按逐秒变化预览，不许诺30/60fps或未经测量的功耗表现。

固件显式区分STUDIO与HAND分发，并将五组按钮放入圆屏安全范围。新款使用既有OFL字体的专用子集，检查正屏/预览的数字、冒号和小字，避免fallback掩盖缺字；原21款字库保持。共用有界行缓冲绘制，无每款全屏常驻缓存。

已检查：九款、00:00/10:08/23:59、全部四个秒值/常显几何、常显同分钟稳定、逐秒启停、筛选、放大与关闭、圆屏文字边界、1440px及390px页面布局；离线文件实际在Chrome以`file:`载入，字体有效、无网络资源请求、无控制台错误。浏览器检查不等于原生绘制、主观验收或真机功耗验证。

原稿阶段的临时HTTP服务与两个测试标签已关闭。本轮固件实现复用[表盘说明](../../../WATCHFACES_UI.md)中的表盘/设置/启动恢复与资源生命周期回归，50项主机检查及ESP32-S3构建通过，已输出466×466的LVGL审图；发布状态以仓库Release与发布记录为准。
